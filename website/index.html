Frequently Asked Questions

Honest answers about VORTEX security and privacy principles.

Do you log my browsing activity?
No. VORTEX VPN does not store, monitor, or inspect any web destinations, page contents, or unencrypted payloads. Only anonymous, aggregate daily threat counters are recorded.
Why does VORTEX use the WireGuard protocol?
WireGuard uses modern cryptographic primitives (Curve25519, ChaCha20, BLAKE2s) and runs at near-wire speeds with significantly less code complexity than OpenVPN or IPsec.
How does the DNS Firewall block ads without HTTPS interception?
The DNS Firewall intercepts queries before domain resolution occurs. If a domain is identified as an ad or tracker, it returns 0.0.0.0, preventing the device from ever contacting the ad network. No TLS decryption or certificate manipulation is performed.
